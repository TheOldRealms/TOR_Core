# Plans

Implementation plans live here — one per step per module, named
`YYYY-MM-DD-<module>-step<N>-<step-name>.md`.

A plan is produced from the matching step section of
[`../specs/2026-09-09-module-lifecycle-design.md`](../specs/2026-09-09-module-lifecycle-design.md)
immediately before the work starts, and carries the concrete, module-specific detail the spec
deliberately leaves out: the file inventory, the cross-module references to cut, the csproj
paths to update.

Empty until the first module starts Step 1.
