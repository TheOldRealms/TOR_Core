# Plans

One implementation plan per epic per module, named `<module>-<epic>.md` —
e.g. `crafting-framework.md`, `bountymaster-modularize.md`.

Written from [`../templates/epic-plan.md`](../templates/epic-plan.md) immediately before the
work starts. A plan carries the concrete, module-specific detail the spec deliberately leaves
out: the file inventory, the edges to cut, the csproj paths.

**Keep plans under two pages.** Project-wide invariants live once in
[`../CONSTRAINTS.md`](../CONSTRAINTS.md) and are referenced, never copied. A plan that restates
them is a plan nobody finishes reading.
