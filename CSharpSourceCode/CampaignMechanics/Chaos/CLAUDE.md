# CampaignMechanics/Chaos

**`ChaosCampaignBehavior`** (`: CampaignBehaviorBase`) — the Chaos faction/invasion
mechanic: escalating incursions from Chaos-aligned forces (spawned via
`CampaignMechanics/TORCustomSettlement/Component/ChaosPortalComponent` portals),
independent of the normal kingdom-war system. Added in `SubModule.InitializeGameStarter`.
