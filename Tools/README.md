# TOR_Core Tools

This folder contains various tools for The Old Realms mod development and translation.

## Available Tools

### TranslationTools/
Tools for managing and updating translation files.

**Quick Start for Translators:**
1. Navigate to the `TranslationTools` folder
2. Double-click `merge_translation.bat` (Windows)
3. Enter your language code and press Enter
4. Done!

See `TranslationTools/README.md` for detailed instructions.

## Folder Structure

```
Tools/
└── TranslationTools/          - Translation management tools
    ├── merge_translation.bat  - Double-click to run
    ├── merge_translation.ps1  - PowerShell script
    └── *.md                   - Documentation files
```
